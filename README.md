# 100-Day Physique Landing Page

A simple, responsive landing page for:

> **Build an Impressive Physique Naturally in 100 Days**

## Structure

```text
physique-100-days-landing-page/
├── index.html
├── style.css
└── README.md
```

## Run locally

Open `index.html` directly in your browser.

For a better development workflow, use a local development server such as VS Code's Live Server extension.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `README.md`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub will provide your published website URL.

## Before publishing

Update these items:

- `YOUR BRAND` with your actual brand name.
- The hero image with your own physique or transformation image.
- The final CTA link (`href="#"`) with your application, payment, or booking link.
- The footer copyright information.
- Any offer details that change.

## Important

The current version is a static front-end landing page. It does not include:

- Payment processing
- Form submissions
- User authentication
- Calendar booking
- Analytics
- Backend functionality

Those should be connected separately based on the tools you choose.
